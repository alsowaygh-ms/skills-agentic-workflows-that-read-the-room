## Recent updates worth watching

- **Pull requests:** Stacked pull requests are generally available, so you can split large changes into smaller PRs that are reviewed independently and merged together. ([Changelog, Oct 6, 2026](https://github.blog/changelog/2026-10-06-stacked-pull-requests-generally-available))
- **GitHub Copilot:** Local sandboxing is generally available in Copilot CLI, the Copilot app, and VS Code sessions using Agent Host. It restricts what Copilot-run commands can access on your machine, such as files, network, and credentials. ([Changelog, Oct 7, 2026](https://github.blog/changelog/2026-10-07-local-sandboxing-for-github-copilot-now-generally-available))
- **GitHub Actions:** Checks, workflow runs, and statuses now follow the same retention setting as artifacts and logs, and expired records are cleaned up automatically. Review your retention period. ([Changelog, Oct 1, 2026](https://github.blog/changelog/2026-10-01-actions-retention-now-covers-checks-runs-and-statuses))
